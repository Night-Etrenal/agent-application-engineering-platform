# Architecture

AAEP architecture is organized around strict separation between upstream capability supply, shared Harness foundation engineering, application engineering, and independent products.

Current conceptual chain:

`DeepSeek Harness → Controlled Upstream → AEHP Shared Harness Foundation → AAEP Application Engineering → Independent Applications`

Repository Foundation V1 does not claim that runtime, browser verification, acceptance engine, SDK, adapters or product applications are implemented. Those capabilities require their own Issues, implementation evidence and validation.
