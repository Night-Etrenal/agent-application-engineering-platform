# ADR-0001: AAEP Foundation Boundaries

Status: Accepted for Repository Foundation V1

## Decision

AAEP is an independent application-engineering platform and canonical project repository. DeepSeek Harness remains controlled upstream capability supply. AEHP remains the shared Harness foundation project. UEGP remains universal governance owner. Engineering-Continuity remains continuity provider.

## Consequences

- upstream code is not canonical AAEP state;
- governance is consumed, not duplicated;
- continuity is referenced, not reimplemented;
- downstream product repositories own their business-specific logic and release lifecycle;
- public repository safety boundaries apply from the first commit;
- project-owned license remains a separate owner decision.
