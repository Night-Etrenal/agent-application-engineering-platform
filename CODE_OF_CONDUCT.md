# Code of Conduct

AAEP expects professional, respectful, technically constructive collaboration.

Contributors should:

- discuss technical decisions using evidence and reproducible reasoning;
- critique code, architecture and decisions rather than people;
- avoid harassment, discrimination, threats, doxxing or disclosure of private information;
- respect security, licensing, governance and authorization boundaries;
- disclose conflicts or uncertainty that materially affect a technical decision.

Maintainers may restrict participation when behavior materially harms contributor safety, project security, or engineering integrity.
